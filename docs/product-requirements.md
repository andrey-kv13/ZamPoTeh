# Продуктовые требования (краткая выжимка)

Полная версия с ответами заказчика хранится локально в `ЗамПоТех/` (в git не входит).

- **ЦА:** владельцы авто, в т.ч. без глубоких знаний; регион MVP — РФ.
- **Отличие:** один запрос своими словами → справка по **конкретному** авто в гараже, а не обход всех каталогов вручную.
- **Данные:** сейчас только открытые источники; платные каталоги — очередь 2, с согласованием бюджета.
- **Юридически:** disclaimer, согласие на ПДн, история по VIN без личных данных прежнего владельца.
- **Монетизация:** не зафиксирована; исследование моделей — в backlog.

Архитектура бота: [architecture-bot.html](./architecture-bot.html).
